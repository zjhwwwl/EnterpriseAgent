## 复现

按项目部署文档启动主 API，完成本机密钥、LLM 和知识索引配置，再显式运行：

```powershell
.\.venv\Scripts\python.exe scripts\evaluate-agent-live.py --allow-live --model-label deepseek-flash
```

缺少 `--allow-live` 会在发送任何 HTTP 请求之前退出。脚本只允许本机 loopback HTTP 服务，使用公开模拟账号；不读取供应商密钥、不直接调用云接口、不把认证头保存到结果。报告只能写入项目忽略目录 `var/evals/agent-live`，含 JSON、CSV 和 Markdown。复验可能产生 API 费用；同名本机输出会更新，Git 中的历史归档保留。
